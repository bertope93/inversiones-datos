# Inversiones: datos

Descarga automática (GitHub Actions) de cotizaciones, analistas, documentos de la SEC y titulares de prensa públicos
para un informe personal de Power BI. Los CSV se publican comprimidos en la versión `datos`
(Releases), de donde los lee Power BI Service.

- Completa: cada noche. Rápida: dos veces al día, de lunes a viernes.
- Fuentes: Yahoo Finance, SEC EDGAR, Google News. No es asesoramiento financiero.
